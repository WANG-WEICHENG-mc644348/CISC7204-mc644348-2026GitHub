## What is here, and what is not

The project is being developed into a manuscript for a conference submission
and an entry in a data-analysis competition, so this folder publishes the
**design** and withholds the **results**:

| Published | Withheld |
|:--|:--|
| Research question and design | Coefficients, effect sizes and significance tests |
| Data sources and access terms | The raw CGSS `.dta` files |
| Variable construction and model specification | The policy conclusions |
| Figure design and justification | The manuscript text |
| Division of work and timeline | — |

Nothing here is restricted or personally identifying. Where data appear
anywhere in this repository they are de-identified: respondent identifiers
and province/city codes are dropped.

A de-identified subset of the analysis — cleaned data, a pre-executed
notebook, figures and a README — is maintained separately at:

<https://github.com/WANG-WEICHENG-mc644348/data-science-project>

## Data access

CGSS waves are distributed by CNSDA free of charge for academic use, after
registration:

- CGSS 2017 — <https://www.cnsda.org/index.php?r=projects/view&id=94525591>
- CGSS 2023 — <https://www.cnsda.org/index.php?r=projects/view&id=11256439>

The digital-government index is published by the Tsinghua University
Institute for Data and Governance; the policy corpus was retrieved from
public government websites.
